# 🎵 Sonora API

API REST desenvolvida com Django + DRF para gerenciamento de usuários, planos, músicas e eventos.

---

# 🚀 Tecnologias

- Python 3.12
- Django
- Django REST Framework
- JWT (SimpleJWT)
- MySQL
- Docker + Docker Compose

---

## ✅ Pré-requisitos
